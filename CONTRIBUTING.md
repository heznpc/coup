# Contributing

This repository is a single-authored research manuscript. External pull requests are generally not accepted.

## What you can contribute

- **Errata**: If you find a factual error, broken citation, or typo in `paper/main.tex` or `paper/references.bib`, please open an issue describing the problem. Include section / line reference where possible.
- **Citation suggestions**: If you believe a relevant prior work is missing from `paper/references.bib`, open an issue with the full bibliographic entry.
- **Replication notes**: Once the experiments folder contains code, replication reports and bug reports are welcome.

## What is out of scope

- Reframing the paper's argument or expanding its scope.
- Style or wording changes that do not affect content.
- Pull requests that modify `paper/main.tex` without prior discussion in an issue.

## Sensitive reports

For undisclosed personal information, leaked credentials, or other sensitive issues, see `SECURITY.md`.
