# Security Policy

This repository hosts a research manuscript (`paper/main.tex`) and a currently empty experiments skeleton. There are no runtime artifacts, no user-facing services, and no installable packages.

## Reporting sensitive issues

If you find something that should not be public — for example, undisclosed personal information in the manuscript, a typosquat in `paper/references.bib`, or a credential committed in error — please report it privately rather than as a public issue.

Preferred channel:

- GitHub Security Advisories on this repo: <https://github.com/heznpc/coup/security/advisories/new>

Please do not open a public issue or pull request for sensitive reports.

## Out of scope

- General citation corrections, typos, or content disagreements — open a normal issue instead.
- Vulnerabilities in tools used to compile the LaTeX manuscript locally — report those upstream (e.g., TeX Live, latexmk).
